# tsumugi（トーク履歴の整理・検索）

LINEのテキスト履歴を取り込み、質問に沿って整理するアプリです。画面はGitHub Pages、保存・認証・AI処理は既存のSupabaseプロジェクトを使用します。

- 履歴とまとめはSupabaseに保存され、共通ID `marugo` でログインした利用者が共有します。
- OpenAI APIキーはSupabase Vaultに保存します。キーやトーク本文をGitHubに置かないでください。
- PDFはまとめの「PDFとして保存」から、ブラウザーの印刷画面で保存します。
- まとめの「編集」で文章や表のセルを直接修正し、「変更を保存」で保存できます。保存後の内容がPDFとCSVにも反映されます。
- PDFとCSVの保存名には、まとめの先頭の見出しを使用します。
- まとめを表示して「CSVとして保存」を押すと、日本語をExcelで開きやすいBOM付きUTF-8形式で出力します。保存済みのまとめも「開く」から出力できます。
- トーク履歴は複数ファイルを追加するか、保存済み一覧の「使う」を複数選択して、まとめて検索できます。合計は150万文字までです。
- 公開サイトはサインイン画面までアクセス可能です。トーク履歴や結果の参照にはSupabaseへのログインが必要です。
- 共通ログインの初期設定は、既存データの所有者が従来のアカウントでログインして行います。画面の「共通ログインの初期設定」で指定のパスワードを入力すると、既存の履歴・まとめ・VaultのAPIキーを共通IDに引き継ぎます。gourmet本体のアカウント情報は変更しません。
- `docs/` はGitHub Pages用、`supabase/` はデプロイ済みのデータベース定義とEdge Functionのソースです。既存のSupabaseプロジェクトへの反映時はほかのアプリに影響しないよう対象を確認してください。
